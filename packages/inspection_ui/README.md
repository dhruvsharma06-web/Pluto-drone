# Pluto Inspection UI

Material 3 presentation, shared contract v1, no camera or inference dependency. Flutter >=3.27; checked with 3.47.1.

```dart
InspectionApp(controller: appController, cameraPreview: cameraPreview)
```

The caller owns/disposes the controller. UI owns only its subscription. Live start/stop and image selection delegate to the controller; safety confirmation blocks acquisition. On app interruption or navigation away from an active live inspection, UI asks the controller to stop. Result changes are immediate; old input/processing results are suppressed. Obvious incomplete approvals are downgraded for display, but full reference coverage/quality validation remain core obligations.

Actual analyzed `state.image` takes precedence over an injected preview: boxes then attach to that exact upright, unmirrored frame with matching input ID. Image uses BoxFit.contain; portrait/rotated sources are letterboxed, never cropped. A bare external preview has no guessed motor overlays. Source IDs and boxes come from the core, never screen quadrants.

`themeMode`, `demoMode`, `developmentControls` are optional additions. Fixtures arriving from any controller show a persistent simulated-results notice. Explicit demoMode keeps the notice present even before a result. Production leaves demoMode false and developmentControls null.

## Run and check

From this directory: `flutter pub get`, `flutter analyze`, `flutter test`.
From example/: `flutter pub get`, `flutter run`. Preview is a separate Android app (`org.plutoinspection.inspection_ui_preview`) with selectable simulated states; it has no camera/model and makes no classification claim about the illustrative diagram.

## Branding

InspectionMark draws the original rotor-aperture logo. Editable SVG and matching PNG/adaptive Android resources are in assets/brand/. The owned Android preview already uses the custom launcher. Production and preview Android launchers are already updated on this branch. To reapply after regenerating Android scaffolding, run from repo root:

`python packages/inspection_ui/tool/install_app_icon.py`

This copies only the named launcher resources into apps/mobile/android/app/src/main/res. Keep the manifest icon as @mipmap/ic_launcher. The production Android launcher resources are applied on this frontend branch as explicitly requested; runtime/composition files are unchanged. Gradle wrappers ignored by Flutter's generated .gitignore can be regenerated by Flutter tooling if needed.

Real Android/device verification remains pending: the initially connected device disconnected before the native test run. Integration smoke test and screenshot driver are included in example/ for the app owner to run with its device ID. Widget-render screenshots are not device screenshots.
