# Project brief

Build a lightweight OpenCV-based Android Flutter app for students inspecting supplied Pluto drone propeller installation before flight. Main product is the app; website is an overview/showcase. Compare propeller type, motor identity and distinguishable installation orientation against supplied reference, highlight faults and provide correction guidance. Deliver APK, labelled dataset, modular source, technical docs and validation report.

Four owners: research only; frontend (Flutter/Codex and website/Claude); app/runtime/integration; ML/data/training. Individual branches until final integration. No login/cloud/backend/control features by default. Drone, exact variant, photographs and configuration ZIP pending. Exclude old pluto-x-glb.zip. Public images are research leads, not verified labels. Mandatory safe operation: disarmed, motors stopped. A Pass is visual installation verification, not general flight clearance.

Sources: supplied PROBLEM_STATEMENT2.pdf and the user's requests. Handbook v3.0 guides scoped tasks/contracts/evidence; explicit user branch/deadline instructions govern workflow. PDFs themselves are not committed without a team decision on sharing rights.
