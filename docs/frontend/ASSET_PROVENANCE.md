# Asset provenance

- example/assets/illustrative-drone.png: original flat geometry framing diagram, 960x1280. No actual drone reference or installation labels.
- Team photographs: used only in local render review and excluded from the public repository. Optional local tests can supply --dart-define=TEAM_PHOTO_PATH=ABSOLUTE_PHOTO_PATH. No permission to publicly disclose these photographs is assumed.
- assets/fonts/: Roboto files from installed Flutter material-font distribution; accompanying Apache 2.0 licence included.
- assets/brand/: original code-native rotor-aperture vector mark and deterministic raster/adaptive exports. File hashes in provenance.json. Not generated by an image model; no stock/third-party logo.
- Framing guide: native geometry-only illustration; not the actual drone configuration.

The old unrelated Pluto X ZIP was not used. Image generation and inline visualization were considered; this deliverable requires actual widgets, genuine supplied photos and an exact vector logo, so no generated drone/photo or separate HTML mockup was introduced.
